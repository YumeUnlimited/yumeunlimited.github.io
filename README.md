# Yume Unlimited Website

Static website for **Yume Unlimited**, a PC game development and consulting company.

## Files

- `index.html` - page structure and content
- `ja.html` - Japanese version of the page
- `styles.css` - responsive styling
- `script.js` - mobile navigation, header state, and static contact form mailto behavior
- `assets/` - logo, favicon, and hero visual

## Preview

Open `index.html` in a browser. No build step is required.

The contact form opens an email addressed to `yumeunlimited@gmail.com`.
